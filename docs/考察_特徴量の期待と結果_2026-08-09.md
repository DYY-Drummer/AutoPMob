# 考察：性能向上手法として期待したことと結果の関係 — 話題特徴が寄与しなかった原因の実証

作成日: 2026-08-09 ／ 対象: 設定A（1,823ケース・11,146式）・最良モデル reranker-10S
根拠データ: `experiments/pfi_results.json`（PFI, 10 seed）、`experiments/topic_feature_diagnosis.json`（診断, モデル非依存）、`experiments/case_outcomes_seed42.json`（正解・不正解ケース分析, seed=42）
図: `docs/figures/fig_topic_diagnosis.png`（(a) ケース間ベクトル類似、(b) 候補内識別力）

用語: PFI = 順列特徴量重要度（Permutation Feature Importance）。AUC = ROC 曲線下面積（1 特徴だけで正解式と不正解式を並べ替えたときの分離度。0.5 が識別力なし、1.0 が完全分離）。特化度（specificity）= 式の変数のうちケース入出力変数に含まれる割合。stage1 = 候補絞り込み段（0.7×テキスト類似 + 0.3×変数 Jaccard の上位 50 件）。被覆率 = 正解式のうち stage1 候補 50 件に入った割合（Recall@K_correct の上限を与える）。

---

## 1. 結論（先出し）

1. **変数系の特徴は期待どおり働き、話題系の特徴は期待と異なりほぼ寄与しなかった。** PFI では変数系 6 特徴の群置換で Recall@K_correct が 0.743→0.065 に崩壊する一方、話題系 4 特徴の群置換は +0.006（p=0.10、有意でない）。
2. **「TF-IDF→SVD のベクトルがケース間で似すぎていた」という仮説は支持されない。** ケース間クエリベクトルのコサイン類似は中央値 0.218（SVD 空間）・0.070（生 TF-IDF 空間）で、0.5 を超えるペアは 5.4% にとどまる。さらに svd_sim 単独でも全 11,146 式から正解式を分離する AUC は 0.950±0.003 であり、ベクトルが縮退していれば不可能な水準である。
3. **真因は「候補に絞った後は話題で選別できない」ことにある。** 話題の信号は無関係な式を除外する粗い絞り込みには有効で、その仕事は stage1 通過の時点で終わる。候補 50 件の中では svd_sim の AUC は 0.594±0.006 まで低下する（specificity は 0.965±0.001）。すなわち候補内の誤り式は正解式と話題がそろっており、残る選別問題は変数の重なりでしか解けない。
4. **stage1 の混合選抜が候補内で「テキスト類似が高い＝変数が合わない」という見かけの負相関を作る**（候補内 corr(text_sim, io_jaccard) = −0.404）。このため text_sim は候補内で AUC 0.437 と 0.5 を下回り、わずかに逆向きの信号になる。
5. **残っている誤りは話題特徴では救えない。** 再ランクで取り逃した正解式が、その上に居座った誤り式より svd_sim が高い確率は 0.516±0.040（コイン投げと同水準）。しかも一部の誤りは「別文献に載っている数学的に同一の式」を選んだものであり、話題類似はむしろ誤り側を推す（§5.5 例 1）。
6. 副産物として、**stage1 の混合重みが被覆率を下げている**ことが分かった。被覆率は混合 0.920±0.004 に対し変数 Jaccard 単独 0.961±0.002。見逃しの 61.8% は stage1 由来なので、stage1 の再設計が次の介入実験の第一候補である。

## 2. 各特徴の「期待」と「結果」の対比

期待 = 特徴を設計したときに想定した働き。PFI = ケース内置換での重要度（10 seed 平均、正が「その特徴に依存」）。候補内 AUC = stage1 候補 50 件の中で正解行と不正解行をその特徴単独で分離できるか（1,823 ケース平均±SEM）。

| 特徴 | 群 | 設計時の期待 | PFI（p 値） | 候補内 AUC | 判定 |
|---|---|---|---|---|---|
| specificity（特化度） | 変数 | ケース専用に書かれた式（変数が I/O に特化）を優先する | **+0.617** (p<0.001) | **0.965** | 期待以上（支配的な担い手） |
| io_jaccard | 変数 | I/O 変数と式変数の重なりが大きい式が正解 | +0.062 (p<0.001) | 0.947 | 期待どおり（特化度と大部分冗長） |
| input_cov | 変数 | 入力変数を被覆する式が必要 | +0.001 (p=0.76) | 0.891 | 信号はあるが固有寄与は冗長 |
| output_cov | 変数 | 出力変数を含む式が必要 | +0.006 (p=0.009) | 0.814 | 期待どおり・小 |
| gComp（補完性） | 変数 | 既候補集合に欠けた変数を補う式を選ぶ | +0.022 (p=0.008) | 0.815 | 期待どおり（集合特徴の純上乗せ） |
| gCoh（一貫性） | 変数 | 集合内で変数を共有し連立系として繋がる | +0.019 (p=0.001) | 0.720 | 期待どおり・小 |
| text_sim | 話題 | 文脈と式説明文の表層語彙の一致 | −0.003 (p=0.26) | 0.437 | 期待と異なり寄与なし（候補内では逆向き） |
| svd_sim | 話題 | TF-IDF→SVD で言い換えを吸収した意味の近さ | −0.003 (p=0.28) | 0.594 | 期待と異なり寄与なし |
| domain | 話題 | 分野ラベルの一致で同分野の式を優先 | +0.002 (p=0.23) | 0.531 | 期待と異なり寄与なし（修論 §6.6 の合併実験とも一致） |
| gDom | 話題 | 集合の多数派分野に合う式を選ぶ | −0.000 (p=0.91) | 0.647 | 期待と異なり寄与なし |

群まとめ（PFI・ケース内置換）: GROUP_var +0.678 (p<0.001)、GROUP_topic +0.006 (p=0.10)。

読み方の注意: PFI は「訓練済みモデルがその特徴に**固有に**依存する量」、候補内 AUC は「その特徴**単独**の信号量」。input_cov（AUC 0.891, PFI +0.001）のように AUC が高くても PFI が 0 になる特徴は、信号はあるが specificity・io_jaccard と重複しており、置換しても相棒が信号を復元できることを意味する。話題系はそもそも候補内 AUC が 0.44〜0.65 と低く、そのうえ変数系と重複する分しか持たないため、PFI・アブレーション（reranker-2+Svd −0.002, p=0.48）の双方で 0 になる。

## 3. 仮説「ケース間でベクトルの差が小さかった」の検証 — 支持されない

意味の近さが効かない原因として「TF-IDF→SVD のベクトルがケース間で似てしまい、区別が付かない」という可能性を検証した（図 (a)）。

| 測定 | 平均 | 中央値 | p95 | >0.5 の割合 |
|---|---|---|---|---|
| ケース間クエリベクトル（SVD 空間 256 次元） | 0.247 | 0.218 | 0.509 | 5.4% |
| ケース間クエリベクトル（生 TF-IDF 空間） | 0.088 | 0.070 | 0.196 | 0.7% |
| 式ベクトル間（SVD 空間） | 0.068 | 0.047 | 0.209 | 0.3% |

（コサイン類似。平均は閉形式で厳密、分位点は 20 万ペアの無作為標本。）

- ケース間の類似は大部分が 0.5 未満で、ベクトルはケース間で十分に離れている。SVD への射影は類似を約 3 倍押し上げる（平均 0.088→0.247）が、縮退には遠い。
- 決定的なのは全 DB に対する識別力で、svd_sim 単独の AUC は 0.950±0.003、text_sim は 0.913±0.003。**ベクトルの差が失われていれば、この分離は生じない。**
- また候補 50 件の中でも svd_sim の値のばらつきは消えていない（候補内 std 0.121 > 全体 0.075）。「値がどれも同じになるから効かない」のではなく、「値の違いが正誤と対応しない」（次節）。

したがって、ベクトルの計算方法（TF-IDF→SVD）の不備が原因ではない。意味の近さは信号として存在するが、**変数の重なりという、より強い信号（io_jaccard の全 DB AUC 0.999）に包含されている**ことが原因である。

---

## 4. 真因：候補に絞った後は話題では選別できない

同じ特徴の識別力を「全 DB 相手」と「stage1 候補 50 件の中」で比べると、話題系だけが崩れる（図 (b)）。

| 特徴 | 全 DB AUC | 候補内 AUC |
|---|---|---|
| io_jaccard | 0.999±0.000 | 0.947±0.002 |
| svd_sim | 0.950±0.003 | 0.594±0.006 |
| text_sim | 0.913±0.003 | 0.437±0.007 |

崩れ方は 2 つの機構で説明できる。

**(i) 候補は話題がそろっている。** stage1 はテキスト類似を 0.7 の重みで使って候補を選ぶため、候補 50 件は最初から話題の近い式が集まる。候補の出所を実測すると、ケースの出典文献と同じ文献の式は候補の 27.1%（誤り候補に限ると 22.2%）に過ぎず、**残り約 8 割は他文献由来**である。それでも誤り候補の svd_sim は同一文献由来 0.399 / 他文献由来 0.370 と正解式と同水準に高い。教科書・論文間で標準的な物理式（物質収支・熱収支など）が繰り返し現れるため、話題の近い式は文献をまたいで大量に存在し、話題では正解文献の式を選び出せない。

**(ii) 混合選抜が作る見かけの負相関（選択効果）。** 候補は「0.7×テキスト類似 + 0.3×Jaccard が高い」式だけの集合なので、その中ではテキスト類似が高いことは相対的に変数が合っていないことの裏返しになる。実測で候補内 corr(text_sim, io_jaccard) = −0.404、corr(text_sim, specificity) = −0.392（seed=42、423 ケース平均）。正解は変数側で決まるため、text_sim は候補内でわずかに逆向きの信号（AUC 0.437）になる。

一方、変数系は候補内でも AUC 0.72〜0.97 を保つ。ケースが式集合から構成され、ケースの I/O 変数が正解式の変数と整合するというデータの成り立ち上、変数整合が正解の定義に最も近い信号だからである。

## 5. 正解・不正解ケースの分析（最良モデル reranker-10S, seed=42, テスト 423 ケース）

seed=42 の Recall@K_correct は 0.791。完全に解けたケース 212/423（50.1%）、残り 211 ケースで正解式 435 本を取り逃した。

### 5.1 失敗の分解：どこで取りこぼしたか

| 取り逃した正解式 435 本の内訳 | 本数 | 割合 |
|---|---|---|
| stage1 見逃し（候補 50 件に入らなかった） | 269 | **61.8%** |
| 再ランク見逃し（候補にはいたが上位 K_c から漏れた） | 166 | 38.2% |

誤りの主因はむしろ stage1 にある。被覆率の分析（§1-6）で示したとおり、stage1 の混合重みを変数寄りにすれば被覆率の上限は 0.920→0.961 に上がるので、ここが次の介入実験の第一候補になる。

### 5.2 解けたケースと落ちたケースの違い

| 属性 | 解けた (n=212) | 落ちた (n=211) | Mann-Whitney p |
|---|---|---|---|
| 正解式数 K_c | 2.13 | 5.34 | p<0.001 |
| 入力変数数 | 10.8 | 17.8 | p<0.001 |
| ソース数 | 1.61 | 1.36 | p<0.001 |
| 被覆率 | 1.000 | 0.829 | p<0.001 |
| sep(specificity) | +0.682 | +0.590 | p<0.001 |
| sep(io_jaccard) | +0.472 | +0.234 | p<0.001 |
| sep(svd_sim) | +0.104 | +0.023 | p<0.001 |
| sep(text_sim) | +0.019 | −0.011 | p=0.061 |

（sep = そのケースの候補内での「正解行の特徴平均 − 不正解行の特徴平均」。）

- 落ちたケースは正解式数・入力変数数が大きい。既報の難易度プロファイル（式数・入力変数数が増えると低下）と一致する。
- 解けたケースは全件が被覆率 1.0。落ちたケースでは被覆率自体が 0.83 に落ちており、stage1 の取りこぼしが失敗と強く結びつく。
- どの特徴の sep も落ちたケースで縮む。つまり落ちたケースは「変数でも話題でも分離しにくい」ケースであり、話題特徴が変数特徴の穴を埋める補完関係は見られない。

### 5.3 話題特徴で救えたか（反実仮想）— 救えない

再ランク見逃しが起きた 131 ケースについて、「取り逃した正解式 m」と「その上に居座った誤り式 w」の全ペアで、特徴値が m > w となる割合（その特徴を強めれば順位を戻せる見込み）：

| 特徴 | P(m > w) |
|---|---|
| svd_sim | 0.516±0.040（コイン投げと同水準） |
| domain | 0.494±0.011 |
| text_sim | 0.368±0.038（むしろ逆） |
| specificity | 0.512±0.005 |
| io_jaccard | 0.375±0.025（誤り側の方が高い） |

- 話題特徴（svd_sim・domain）を強めても、取り逃しは半分の確率でしか救えず、系統的な改善にならない。
- 注目すべきは io_jaccard の 0.375：**誤り式の方が変数の重なりは大きい**。つまり残存誤りは「モデルが変数信号に従った結果として合理的に選んだが、正解定義上は誤り」というケースで、現行の全特徴の外側にある（§5.5）。

### 5.4 選択効果の実測

候補内 corr(text_sim, io_jaccard) = −0.404、corr(text_sim, specificity) = −0.392。§4(ii) の見かけの負相関を実測で確認した。

### 5.5 具体例

**例 1（再ランク見逃し・話題類似はむしろ誤りを推す）** ケース dae_X1_040（回分発酵、入力 t・μ → 出力 X、K_c=1）。正解は出典文献の dX/dt = μX（svd_sim 0.369）。その上位に**別文献（ワイン発酵モデルの総説）の数学的に同一の式** (1/X)dX/dt = μ（svd_sim 0.72）と dX/dt = μ·X（svd_sim 0.584）が並んだ。3 式とも specificity = io_jaccard = 1.0 で変数特徴は識別不能、話題特徴はむしろ誤り側（別文献版）を強く推す。正解の定義が出典文献に紐づく以上、この型の誤りはどの特徴でも救えず、**話題特徴を強めると悪化する**。

**例 2（再ランク見逃し・向きの情報が無い）** ケース dae_X1_089（非等温 CSTR の線形化応答、出力 C_A'、K_c=1）。同一文献の対になった式 dC_A'/dt = a11 C_A' + …（正解）と dT'/dt = a21 C_A' + …（誤り）が specificity = 1.0・io_jaccard = 1.0・svd_sim 0.321 vs 0.323 と全特徴で同値になり、誤り側が上位に来た。両式の違いは「**どの変数を左辺で決める式か**」（C_A' か T' か）であり、現行特徴は式の変数集合しか見ないため向きを表現できない。出力変数を左辺に持つかどうかという構造情報が今後の特徴候補になる。

**例 3（stage1 見逃し・類似式ファミリによる候補の占拠）** ケース dae_X2_034（CSTR + 熱交換の制御系、K_c=2）。データベースには教科書由来の熱収支式 VρCp dT/dt = … の変種が多数あり、stage1 候補はこのファミリで埋まった。正解の 1 本（制御応答式 T'(t) = ΔSP[…]）は候補 50 件に入らず（被覆率 0.5）、再ランク以前に敗退した。

**例 4（解けたケース・参考）** ケース dae_X9_030（充填層洗浄、K_c=9）は正解 9 式が全て上位を占めた。全正解式が specificity = 1.0 で、svd_sim は 0.43〜0.62 とばらつくが順位に影響しない。

## 6. まとめ：期待と結果の関係と、その原因

1. **期待どおりだった点**: 変数系特徴は設計意図どおり正解の識別を担った。特化度が支配的（PFI +0.617、候補内 AUC 0.965）で、集合特徴（gComp・gCoh）は逐次選択と組み合わせた小さいが有意な純上乗せを持つ。
2. **期待と異なった点**: 話題系特徴（text_sim・svd_sim・domain・gDom）は再ランクに寄与しなかった。原因は次の 3 つで、いずれも実測で裏づけた。
   - **冗長性**: 正解の定義が変数整合とほぼ同値になるデータ構造のため、話題の信号（全 DB AUC 0.95）は変数の信号（同 0.999）に包含される。話題が有効なのは粗い絞り込みまでで、その仕事は stage1 で終わる（候補内 AUC 0.594）。
   - **選択効果**: 混合選抜が候補内に text_sim と変数系の負相関（−0.40）を作り、text_sim は候補内でわずかに逆向きになる（AUC 0.437）。
   - **正解定義との不整合**: 標準的な物理式は文献をまたいで重複するため、話題類似は「別文献の同一式」を推してしまい、出典に紐づく正解定義とかみ合わない（例 1）。
   - なお「ベクトルがケース間で似すぎている」仮説は棄却された（ケース間コサイン中央値 0.218、svd_sim の全 DB AUC 0.950）。TF-IDF→SVD という計算方法の不備ではない。
3. **残存誤りの性質**: 見逃しの 61.8% は stage1 の取りこぼしで、被覆率の上限差（混合 0.920 vs Jaccard 単独 0.961）から stage1 再設計で機械的に縮められる見込みがある。残る再ランク誤りは全特徴で P(救済)≈0.5 以下の難ケースで、(a) 別文献の等価式（正解定義の問題）、(b) 式の向き（どの変数を決める式か）の欠落、が具体的な型として同定できた。
4. **論文での位置づけ**: 「話題特徴は効かなかった」で終えず、(i) 信号としては存在する（AUC 0.95）、(ii) どの段階で・なぜ冗長になるか（候補絞り込み後・変数信号への包含+選択効果+正解定義）、(iii) 強めても救えない（反実仮想 0.516）——まで特定した点を考察の主張にする。分野一致の負の結果（§6.6）と合わせ、「本課題は同じ話題ではなく同じ変数で解ける」という一貫した機構的結論になる。
