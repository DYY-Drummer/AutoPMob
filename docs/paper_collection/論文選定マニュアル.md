# 論文選定マニュアル

**プロジェクト**: AutoPMob — 物理モデル自動構築
**目的**: 32 分野 × 各 10 報 ≈ 320 報の学術論文を体系的に収集し、データベース $\text{DB}_\text{eq}$ を拡張する
**作成日**: 2026 年 5 月
**対象読者**: 研究者本人および共同収集者（学部生・共同研究者）

---

## 0. 本マニュアルの使い方

1. **§1 ～ §2** を読んで「本研究のタスク」と「選定の大原則」を理解する。
2. **§3** の必須項目チェックリストで各論文を 1 次評価。
3. **§4** の推奨項目で Tier 判定。
4. **§5** の Google Scholar 検索戦略で論文を探す。
5. 採用論文を Excel テンプレート（`論文評価チェックシート.xlsx`）に記録。
6. PDF を `pdfs/<domain>/` に保存。

---

## 1. 本研究のタスクと評価軸

### 1.1 研究のゴール

ユーザーが指定する **「入出力変数 + プロセス説明文」** に対し、文献データベースから **必要な数式集合**（multi-positive ）を自動で予測する。

```
入力 q = (context, V_input, V_output)
        ↓ Stage 1: 古典 IR で 50 式に絞り込み
        ↓ Stage 2: GNN リランカーで最終ランキング
出力 = 必要な数式の集合 (multi-positive correct set)
```

### 1.2 「良い論文」とは何か

専門家がまず確認するのは：
> 「この論文の式が、本研究のタスクで *正解集合* として機能するか？」

これを **4 つの軸** で評価する：

| 軸 | 評価基準 | なぜ重要か |
|----|---------|---------|
| **1. 物理モデル性** | First-principles（保存則ベース）か？ | データドリブン手法は GNN の物理推論と相性悪 |
| **2. 数式の抽出性** | 番号付き、変数定義あり、LaTeX 化可能か？ | 抽出パイプラインの品質を決定 |
| **3. コンテキスト性** | 仮定・条件・物理的意味が明示されているか？ | 文脈埋め込みの質が GNN の性能を左右 |
| **4. 再利用性** | 他の文献と組合せ可能な一般性があるか？ | 文献横断の正解集合を構成可能 |

## 2. 数式抽出パイプラインとの整合性

論文の数式は **Gemini 2.5 Pro による Structured Output 抽出** にかけられる。抽出スキーマ：

```json
{
  "source_id": "<pdf_filename>",
  "eq_id": "eq_<n>",
  "equation": "<LaTeX>",
  "variables": { "<symbol>": "<definition>" },
  "context_text": "<surrounding physical meaning>",
  "domain": "<domain label>"
}
```

つまり、**LaTeX 化可能な数式**、**変数定義の明示**、**周辺文脈の十分性** が抽出の前提となる。これを満たさない論文は無条件で除外。

---

## 3. 必須項目（除外条件）

**1 つでも欠ければ採用不可**：

```
□ 必須 1: 番号付きの主要数式が 5 件以上含まれる
□ 必須 2: 全変数に明示的な定義がある（記号表 or 文中）
□ 必須 3: First-principles model（ODE / PDE / 代数方程式）が中心
□ 必須 4: モデルの仮定 (assumptions) が記載されている
□ 必須 5: PDF が抽出可能な品質（OCR で文字認識可能、画像化されていない）
□ 必須 6: ニューラルネットワーク／回帰モデル *のみ* ではない
```

---

## 4. 推奨項目（Tier 判定）

**多いほど高評価**：

```
■ 推奨 1: 物理量の単位が明示されている (mass [kg], rate [mol/s] 等)
■ 推奨 2: Case study / Simulation results セクションがある
■ 推奨 3: Validation experiment との比較がある
■ 推奨 4: 変数命名が分野標準に従う (記号揺れが少ない)
■ 推奨 5: 適用範囲・限界の議論がある
■ 推奨 6: 連立方程式系 (multi-equation system) として記述
■ 推奨 7: 状態方程式・境界条件が明示
■ 推奨 8: 物理プロセスの図 (schematic) がある
```

### Tier 判定基準

| Tier | 必須 | 推奨 | 排除 | 採用判定 |
|------|---:|---:|---:|---------|
| **Tier 1** ★★★ | 6/6 | 6 以上 | 0 | 最優先採用 |
| **Tier 2** ★★ | 6/6 | 4-5 | 0 | 推奨採用 |
| **Tier 3** ★ | 6/6 | 1-3 | 0 | 補完採用 |
| 不採用 | <6 | — | ≥1 | 除外 |

### 各分野の目標構成

| Tier | 各分野の目標報数 | 役割 |
|------|---:|------|
| Tier 1 | 3-5 報 | 分野の **standard reference** 教科書の章レベル |
| Tier 2 | 3-5 報 | 高被引用 review / 体系的 process modeling 論文 |
| Tier 3 | 2-3 報 | 直近 5 年の応用論文、validation 含む実プロセス例 |
| **合計** | **8-13 報/分野** | 32 分野 × 10 報 ≈ **320 報** |

---

## 5. 排除項目（採用不可）

**1 つでも該当すれば即除外**：

```
✗ 排除 1: 数式が画像（スキャン）のみで LaTeX 化不可能
✗ 排除 2: ニューラルネットワーク・回帰のみで物理理解を欠く
✗ 排除 3: 装置特化の経験式のみで他文献と組合せ不可能
✗ 排除 4: 数式が断片的・連立系として完結していない
✗ 排除 5: 変数の定義が散逸・記号が文献内で矛盾
✗ 排除 6: 著者が「これは経験式である」と明示しているもの
```

## 6. 専門家の追加観点

### 6.1 記号揺れの代表性を意図的に含める

同じ物理量を異なる記号で表現する文献を **意図的に混在** させる。

**例**：
- 熱伝達係数を $h$ と書く文献、$U$ と書く文献の **両方** を採用
- 体積流量を $F$、$Q$、$\dot{V}$ で表記する文献を混ぜる

これは GNN の **表記揺れ吸収能力** を測る本質的サンプル。

### 6.2 連立方程式系を優先

単一式（例：Beer-Lambert 1 式）より、**3-5 式の連立系**（CSTR の物質収支 + エネルギー収支 + 反応速度等）を優先する。

これにより multi-positive 検索の真価を測れる。

### 6.3 文献横断シナリオの種を含める

「化学工学 + 制御理論」「反応工学 + 伝熱」のような **複合領域論文** を必ず含める。これらは `multisource_original` ケースの素材になる。

### 6.4 「教科書」と「論文」のバランス

| 種別 | 役割 | 推奨比率 |
|------|------|---:|
| 教科書 | 普遍式（Fourier, Bernoulli 等）を網羅、安定した基盤 | **30%** |
| 論文 | 特定応用での組合せ、現実的シナリオ | **70%** |

## 7. Google Scholar 検索戦略

### 7.1 基本テンプレート

```
("<DOMAIN>") AND
("dynamic model" OR "mathematical model"
 OR "first-principles" OR "kinetic model")
AND
("differential equation" OR "ODE" OR "mass balance"
 OR "energy balance" OR "rate equation")
NOT ("neural network only" OR "purely data-driven")
```

### 7.2 各分野のキーワード集

→ 別ファイル **`論文検索キーワード_32分野.csv`** 参照。

### 7.3 効率的な探索順序

1. **教科書** を先に検索（"textbook" "fundamentals" "principles" を追加）
2. **Review 論文** を次に（"review" "survey" "tutorial"）
3. **応用論文** を最後に（具体的なプロセス名・装置名を含めて）

### 7.4 採用時の注意

- **被引用数 50 以上**を目安（標準性の指標）
- **2010 年以降**を推奨（数式が LaTeX 化されている可能性高）
- **オープンアクセス**または機関アクセスで PDF が取得可能か事前確認

### 8.3 メタデータ記録

各論文を Excel テンプレート（`論文評価チェックシート.xlsx`）に記録：

- Tier 判定
- 必須/推奨項目の充足

## 9. 抽出パイプラインへの投入

1. PDF を `<source_id>` として `pdfs/<domain>/` に配置
2. `python extract_equations.py <pdf_path>` で抽出
3. `python build_equation_graph.py --add <pdf_path>` で統合
4. `python validate_dataset.py` で重複検出・健全性チェック
5. `python build_graph_data.py` で二部グラフ再構築

## 10. よくある質問

### Q1. 標準教科書（Fogler など）が PDF で取得できない場合は？
**A1.** 図書館コピーや章単位の抜粋 PDF でも可。重要なのは **数式と変数定義** が明示されていること。Chapter ごとに `source_id` を変えて抽出（既存運用と同じ）。

### Q2. 同じトピックを扱う論文が複数あるとき、どれを優先する？
**A2.** Tier 判定で同点なら、以下の順で優先：
1. **高被引用** (citations top 10%)
2. **連立方程式系** が明確
3. **記号揺れ** の代表的な命名（例：$h$ vs $U$）
4. **最新** （2020 年以降）

### Q3. 1 つの論文に数式が 100 件以上ある教科書は？
**A3.** 採用。`extract_equations.py` が 80 ページごとにチャンク分割するため、長大な教科書も処理可能。**1 つの教科書 = 1 つの `source_id`**（章で分割する場合のみ複数）。

### Q4. ハンドブック（LLM 生成）と論文の重複が心配。
**A4.** `extract_equations.py` 抽出時に `validate_dataset.py` が重複式を検出・除外する。論文の抽出後に必ず実行。

### Q5. 仮説 B との関連は？
**A5.** 仮説 B（関連性の低い式の効用）の検証のため、**ターゲット分野以外の論文も意図的に含める**。ただし「無関係でも数式品質は高い」ものに限定（必須項目はすべて満たす）。
