## 1. 成果物

学会トップ発表（NeurIPS・CVPR 等）水準のビジュアル品質をもつ、**単一 HTML ファイル**としてエクスポート可能な研究紹介 Web スライド。スクロール型で、セクション間を滑らかに進められる"動ける"スライド。

## 2. プロジェクト概要

- **研究テーマ**：グラフニューラルネットワーク（GNN）を用いた物理モデルの自動構築
- **用途**：ゼミで口頭発表する「研究紹介」（配布用 PDF と併用）
- **対象聴衆**：グラフニューラルネットワークも物理モデルも予備知識のない **学部卒業生 / 博士前期課程 1 年**
- **話者**：宮村（加納研究室・博士課程）
- **発表時間想定**：20 分前後 + 質疑

### §0 話の流れ（Hero 直後、常に表示）

発表の全体像を目次として示す。5 ステップの横並びカード：

> **目的** → **関連研究** → **手法** → **結果と考察** → **まとめ**

### §1 目的 Purpose（原稿 §1 全体）

4 つのサブトピックをカード構成で：

- **§1.1 物理モデルとは何か**：科学原理に基づく数式の組合せで物理量の関係を記述したもの（**「入力→出力」という狭い定義は取らない**）。
  - 典型例として連続槽型反応器（CSTR）の数式モデルを 3 式ほど出す（質量保存・熱収支・反応速度式）。
  - ここで「制御構造」「目的関数」「暴走反応」などの用語は使わないか、初出時に括弧で説明。
- **§1.2 誰が物理モデルを必要とするか**：工場オーナーではなく **エンジニア・研究者**（プロセス設計／制御系設計／最適化／安全解析）。4 アイコン並べ。
  - プロセスシミュレータ（Aspen 等）で足りるケースと、**足りないケース**（新規プロセス／複数分野連成／文献再現）を対比。
- **§1.3 現状の課題**：専門家の手作業で **数日〜数週間**（「数週間〜数ヶ月」は誇張気味だったので修正済み）。
- **§1.4 本研究の目的**：**文献の実在数式から、自由度的に解ける（未知数の数＝独立式の数）数式群を自動選択する手法の確立**。

### §2 関連研究 Related Work（原稿 §2 全体）

3 流派を 3 カラムで比較。ただし「我々の流派 C」のカラムだけ強調表示し、**§2.3 末にナラティブブリッジ**を入れて §3 へ繋ぐ。

- **流派 A（シンボリック回帰）**：実験データから $y \approx f(x)$ を探索。
  - 具体例：**AI Feynman は 1 公式あたり $10^5$ 点の入出力ペアが必要**（例：$F = G m_1 m_2 / r^2$ の再発見に 10 万組）。
  - 短所：設計段階・新規プロセスでは使えない。
- **流派 B（大規模言語モデル直接生成）**：GPT-4 / Claude / Gemini に自然言語で聞く。
  - 代表研究：ChemCrow (Bran 2023)、Ramos ら (2024)。
  - 短所は **項目ごとに比較対象を明示**：
    - ハルシネーション（対 数式検索方式）
    - 根拠追跡の困難（対 数式検索方式）
    - 組合せ整合性の不安定性（対 シンボリック回帰・数式検索方式）
- **流派 C（文献からの数式検索、本研究）**：
  - ハルシネーションゼロ、出典追跡可能、正解集合を式 ID 集合として定義できる。
  - **★ ナラティブブリッジ（§3 への導入）**：
    > 「数式データは個体として独立しつつ互いに関係（変数共有・共起・入出力連鎖）で繋がっている → この『個体＋関係』のデータ構造を眺めたときに最初に想起されたのが **SNS** → SNS は要するに **グラフ** → グラフを扱う学習手法と言えば **グラフニューラルネットワーク（GNN）**」
  - この部分は **図でも見せたい**：SNS 対応表（人物＝式、友人関係＝共通変数、A↔B↔C ＝ 式$e_1$—変数$T$—式$e_2$）。

### §3 手法 Method（原稿 §3 全体）

5 節構成：

- **§3.1 問題設定**：入力（プロセスの自然言語記述、入出力変数集合） → 出力（連立可能な式集合）。
- **§3.2 基本戦略：2 段階の数式検索**：
  - Stage 1（古典的・$O(N)$）：TF–IDF 文脈類似度 + Jaccard 変数一致度で上位 $K = 50$ 件
  - Stage 2（精密・$O(K)$）：多層パーセプトロン（MLP）リランカーで並べ替え
  - **Recall@50 = 99%+** を具体値として強調
  - **Stage 1 スコアの式**：$S = \alpha \cdot \mathrm{sim}_\mathrm{text} + (1-\alpha) \cdot \mathrm{sim}_\mathrm{var}$、$\alpha = 0.7$
- **§3.3 グラフ構造とモデルの入出力**（4 サブ節）：
  - 3.3.1 **なぜグラフ構造か**：3 つの作業仮説（変数共有 / 共起 / 入出力連鎖）— 「仮説」と明記、反例併記。
  - 3.3.2 **グラフの構成**：式ノード 3,244 + 変数ノード 3,704 の **二部グラフ**、CodeBERT 768 次元。
  - 3.3.3 **Stage 2 リランカーの入出力**：$\phi(q, c) \in \mathbb{R}^{10}$ を MLP（隠れ層 64 × 2）→ スコア。
    - ドロップアウト $p = 0.1$ は軽く図示（64 次元のうち 6〜7 個が 0）
  - 3.3.4 **10 次元特徴ベクトルの内訳**：基本 7 次元 + Set-aware 3 次元。
    - **厳密には MLP だが、グラフ特徴量を入力とする「GNN 的アプローチ」** と正直に位置づける。
- **§3.4 単発選択から組合せ選択へ**：複数式正解（44%）を評価するには **候補同士の組合せ** を見る必要がある、の動機付け。
- **§3.5 Set-aware 特徴量の定義**：
  - **補完性（Comp）**、**一貫性（Coh）**、**ドメイン整合性（Dom）** の 3 つ。
  - スライドでは式は必須ではなく、**直感的な概念図**（参照集合 $S_\mathrm{ref}$ とクエリ変数のカバー図）で見せる。

⚠️ **映画キャスティングアナロジーは v2 で使っていたが、v3 では削除**。SNS アナロジー（§2.3）だけで十分。

### §4 結果と考察 Results & Discussion（原稿 §4 全体）

5 節構成：

- **§4.1 データセット**：
  - **3,244 式**（論文 PDF 2,574 + ハンドブック 670、39 PDF + 各章）、ドメイン 813 種
  - **1,107 ケース**（variant 4 種：original 93 / paraphrased 279 / random_io 733 / swap_io 2）
  - **文献単位（source_id）で train/val/test = 60/20/20 分割** と、その理由（ケース単位だとデータリーク）
  - プロンプト全文はスライドには載せない（PDF に誘導）
- **§4.2 評価指標**：
  - **MRR_first**：最初の正解式の順位の逆数平均、値域 $[1/N, 1]$
  - **Recall@K**：上位 $K$ 件に含まれる正解の割合（情報検索の標準指標、$|R_q \cap \mathrm{Top}_K(q)| / |R_q|$ の平均）
  - **MAP**：平均適合率、図で直感を示す（正解が前方に詰まっているほど高い）
  - 3 指標の違いを 1 枚の表で対比
- **§4.3 主要な結果**：
  - 3 手法比較表（ベースライン → リランカー 7 次元 → リランカー + Set-aware 10 次元）
  - 10 シード平均、MRR_first = **0.965**、Recall@3 = **0.942**、MAP = **0.955**
  - **統計的有意性**：対応あり $t$-検定、$p$ 値の意味を 1 行で添える
    - MAP: $p = 0.004$ / 複数式 Recall@3: $p = 0.032$ / 複数式 MRR_worst: $p = 0.024$
    - MRR_first（全体）: $p = 0.231$（有意ではない）
- **§4.4 考察**：
  - 主結論：**「単発選択では差を主張できず、複数式の組合せ評価で有意な改善」**
  - 大きな引用として：**「グラフ構造の真価は、単一対象のスコアリングではなく、対象集合の整合性評価で発揮される」**
- **§4.5 今後の展望**：
  - 変数レベル意味類似度導入（現状は記号完全一致のみ）
  - データ規模拡大の 2 方向（**単一ドメイン内の増強** と **ドメイン拡張** を分けて議論）
  - 実プロセスでのケーススタディ

### §5 まとめ（原稿 §5 全体）

5 項目を横並びカード or 縦並びステップで：

1. **目的**：物理モデル構築の手作業自動化
2. **関連研究**：シンボリック回帰（データ依存）／大規模言語モデル（ハルシネーション）／数式検索（実在式）
3. **手法**：二部グラフ 3,244 + 3,704 上の 2 段階検索、Set-aware 特徴量
4. **結果**：複数式の組合せ評価で Set-aware が統計的に有意（$p = 0.004$–$0.032$）
5. **展望**：意味類似度導入、データ拡大、実ケーススタディ
