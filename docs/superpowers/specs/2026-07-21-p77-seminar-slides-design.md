## v2 改訂の経緯

v1 は PSE Asia 2026 のポスター P-77 単独の紹介（8 枚）だったが、発表者レビューで
「スライドを読んでも何をやっているか分かりにくい」「抄録だけでは体系的な話に足りない」
との指摘を受け、**全文が公開されている DTU 論文を中心例**に据えて
「MCP で行う研究の構造」を説明する構成に全面改訂した。
発表時間 12 分は維持し、**10 枚**に再構成する（発表者承認済み）。

## 目的（v2）

「LLM に道具を持たせる」研究がどういう構造をしているかを、実例の数値とともに
分かりやすく伝え、次の 3 つの問いに答える：

1. **どんな研究・作業が MCP に向いているか**
2. **どんな作業は MCP でやるべきか（価値が出るか）**
3. **MCP（LLM）に任せてはいけないことは何か**

## 中心例（一次資料・全文あり）

- Jingkang Liang, Niklas Groll, Gürkan Sin,
  "Large Language Model Agent for User-friendly Chemical Process Simulations",
  **arXiv:2601.11650**（2026-01、CC BY 4.0）、DTU（デンマーク工科大学）
- 構成: Claude Desktop（LLM）+ 自作 MCP サーバ（Python/FastMCP）+
  AVEVA Process Simulation（APS）v2025 の Python API
- **ツールは 16 個**（Table 1 を HTML から直接数えて確認。抽出モデルは 18/19 と
  ぶれたが実数は 16）。分類は発表者による: 接続・ファイル系 5
  （aps_connect, sim_open, sim_create, sim_save, sim_status）／読み取り系 5
  （models_list, connectors_list, model_all_vars, model_all_params,
  var_get_multiple）／書き込み・構築系 6（var_set_multiple,
  param_set_multiple, model_add, models_connect, fluid_create, fluid_to_source）
- ケース 1（水-メタノール蒸留の分析・改善）: ツール 7 回で約 2,000 変数から
  要点 24 個を抽出（13 段塔、留出液メタノール純度 84.2 mol%）。改善案 11 個
  （著者採点: とても良い 3・詳細不足 4・的外れ 3・誤解を招く 1・誤り 0）。
  還流比 1.5→1.4→1.45 の反復で純度 84.2→95.1 mol%（目標 95 超）を達成
- ケース 2（ゼロから構築）: 対話型（9 プロンプト）と一発指示型の 2 モード。
  機器の接続と計算実行（Solve）切替は**あえて人間に残す**設計
- 失敗の型（論文記載のまま）: ①算数ミス（改善幅 +10.9% と報告、正しくは
  +12.9%）②根拠のない断言（省エネ 20〜40% と主張、専門家見積は 2〜5%）
  ③雑な単純化（「段効率 100% が最適」）④ツールの穴（接続口の名前が API から
  取れず手動介入）
- 結論: 計算はシミュレータ（決定論）・段取りは LLM・判断は人間。
  「専門性の置き換えではなく増強」

### 用語・文字サイズのルール（v1 から継続、一部更新）

- 全テキスト（図中・表・出典含む）**20pt 以上**、和文は Hiragino Kaku Gothic ProN
- **略称には正式名称を各スライドの初出箇所で併記**。v2 の対象:
  MCP（Model Context Protocol）、LLM（大規模言語モデル）、
  PSE（Process Systems Engineering）、DTU（デンマーク工科大学）、
  APS（AVEVA Process Simulation）。COM・CSTR は v2 では不使用のため対象外
- **API は日常語として扱い併記不要**（聴衆は毎日コードを書く）。同様に
  還流比・収束・蒸留などプロセス工学の学部用語は説明不要
- 難解用語の 1 行説明: AVEVA Process Simulation（Aspen Plus と同類の商用
  プロセスシミュレータ）は初出スライドで説明
- 禁止語（v1 と同一）: フローシート, RAG, TEA, LCA, LNS, MINLP, power-law,
  トークン, 実証, 大幅, 劇的, 画期的, 世界初
- 数値は論文の記載のみ。一般化（問い①〜③の枠）は「論文の結果＋発表者の整理」と
  台本で明示
