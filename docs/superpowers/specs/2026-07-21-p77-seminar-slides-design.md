# P-77 紹介スライド（研究室ゼミ）設計書

作成日: 2026-07-21 ／ 発表者: 丁一洋（かずひろ）

## 目的

PSE Asia 2026 の抄録集から見つけた生成 AI 活用研究 P-77 を研究室ゼミでシェアする。
聴衆に持ち帰らせるものは「潮流」（PSE 分野で LLM エージェント研究が主要トピック化）と
「実践」（自分の研究ツールも MCP で LLM に繋げられる、その設計教訓）の両方。

## 紹介対象

- **P-77**: Large Language Model Assisted Automation for Reactor Process
  Simulation, Synthesis, and Optimization
- 著者: Ting-Yen Chiang, Yu-Sheng Chen, Hao-Yeh Lee, Yan-Ling Yang*
  （国立台湾科技大学 化学工学科）
- PSE ASIA 2026（延世大学、ソウル、2026-07-05〜08）Poster Session P2（7/7 13:30〜14:30）
- 情報源は**抄録のみ**（ポスター発表のため本文なし）。抄録の記載を超える主張はしない。
  成果の表現は抄録の "confirms correct functionality" に合わせ「動作確認済み」とし、
  「実証済み」等の格上げ表現は使わない。

### 抄録の要点（スライド素材）

- LLM を MCP（Model Context Protocol）で Aspen Plus に統合し、
  反応器プロセスのシミュレーション・合成・最適化を自動化する枠組み
- 構造化された 6 フェーズワークフロー
- **60 個超の MCP ツール**。COM ノードパス検証済み、パラメータ制約のバリデーション付き
- COM API では反応セットを作成できないため、**backup ファイルをテキストとして
  直接編集**して回避（複数反応タイプ・単位換算に対応)
- プロセス工学の知識ベースと、誤操作を防ぐ安全ガードを内蔵
- 検証ケース: 混合・加熱・フラッシュ分離・蒸留・CSTR（power-law 反応速度）で
  全フェーズの動作確認

## 制作手順の方針（実装計画への入力）

1. テンプレ pptx の構造（マスター・レイアウト・配色・フォント）を python-pptx で確認
2. 8 枚の本文・図を作成（自作図は 3 点: MCP 概念図、P-77 アーキテクチャ図、×○ルート図。
   いずれも python-pptx の図形配置で作る。スライド 2 のマップは分類×件数の一覧表、
   スライド 5 の対比は 2 カラムの箇条書きとする）
3. ノート欄に台本を記入
4. 検証チェック（下記）

## 検証（受け入れ基準）

- [ ] 8 枚構成で、各スライドにリード文が 1 本ずつある
- [ ] 専門用語の初出に正式名称併記がある（MCP、COM、CSTR、LNS 等）
- [ ] 抄録にない定量的主張・格上げ表現（「実証」「大幅に」等）がない
- [ ] うちの研究室 2 件への言及がスライド 2 にある
- [ ] ノート欄台本の合計が約 12 分（8 枚 × 60〜90 秒）
- [ ] テンプレの配色・フォントが維持され、フォント埋め込み済み
- [ ] PowerPoint（または Keynote）で開いて崩れがない
