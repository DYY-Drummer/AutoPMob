# CACE Paper First Draft Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Produce the first English draft of a journal paper (tentative target: Computers & Chemical Engineering) in `paper/cace/`, derived from the master's thesis, with the LLM comparison and the strengths-and-weaknesses analysis added.

**Architecture:** An `elsarticle` manuscript split into one file per section. Every number in the prose and tables is a TeX macro generated by `paper/cace/make_numbers.py` from the result JSON files, so the text cannot drift from the data. Prose is condensed from `thesis/master_thesis/*.tex`; new sections draw on `docs/LLM比較_長所と短所_2026-11-16.md`.

**Tech Stack:** LaTeX (`elsarticle`, `pdflatex`, `bibtex`, `latexmk`), Python 3.12 (`json`, `pytest`).

**Spec:** `docs/superpowers/specs/2026-11-16-cace-paper-design.md` (Japanese). Executors read both.

**Execution:** Native. One author writes all sections in this session, because the sections share wording, macros and claims.

## Global Constraints

- Judgment is by equation identifier only; no equivalence or notation matching. LLM numbers come from `experiments/llm_db_baseline/id_summary.json`.
- Do not describe duplicated documents or equations as a problem, limitation or future work. The only exception is one sentence in the error analysis (spec §5, 7.7).
- "Source" means one PDF file or one generated reference set. Write "329 PDF files", never "329 documents"; write that no source spans training and testing, never that no document leaks.
  - **Corrected after the final review (2026-11-16):** "no source spans training and testing" is false for ground truths that draw on several sources. Write that each case is assigned to the source that contributes most of its ground-truth equations, that cases assigned to one source stay in one part, and that 37.1% of the test cases of Setting A share a ground-truth equation with a training case (`experiments/llm_db_baseline/split_overlap.json`).
- No statistical tests. Report mean ± SD over 10 splits and the number of splits in which one method beats another.
- Do not mention the symbol-renaming experiment, the document-level split check, augmented cases, or the thesis as a document.
- Do not write "untested" about other notations; write that the experiments cover only queries that share the notation of the ground truth.
- Do not claim the method builds a model, guarantees a solvable set, or is always better than LLMs.
- Abstract: at most 250 words, one unstructured paragraph. Main text (Abstract to Conclusion): 8,500–10,000 words.
- Author-decided items stay as visible `\todo{...}` markers: authors, affiliations, acknowledgments, funding, data availability, AI-use declaration, manual verification of LLM-made data.
- No number is typed by hand in `sections/*.tex` or `appendix.tex`; all come from `numbers.tex`.
- English follows the 11 rules of `feedback_english_writing_style` (active voice, positive form, concrete words, no needless words, parallel form, emphatic words last).
- Commit only files this plan creates or changes; never `git add -A`. PDFs need `git add -f`.

## Review Focus

- A JSON key that is missing or renamed: `make_numbers.py` must stop with the file and key path in the message, not write a blank macro. (Task 2 test.)
- A macro name containing a digit or underscore: TeX would silently read a shorter name. The registry must reject it. (Task 2 test.)
- A difference computed from rounded values: 0.981 − 0.906 gives 0.075 only from unrounded inputs. `diff` takes raw values. (Task 2 test.)
- A value that rounds to zero with a minus sign: never emit "-0.000". (Task 2 test.)
- `numbers.tex` stale against the JSON files: `make_numbers.py --check` exits 1 when the file on disk differs from a fresh build. (Task 2 test; run in Task 9.)

### Task 2: Numbers from JSON

**Files:**
- Create: `paper/cace/make_numbers.py`, `tests/test_paper_numbers.py`, `paper/cace/numbers.tex` (generated)

**Interfaces:**
- Produces:
  - `fmt(x: float, nd: int = 3) -> str` — fixed decimals; a value that rounds to zero prints without a minus sign.
  - `diff(a: float, b: float, nd: int = 3, signed: bool = True) -> str` — rounds `a − b` computed from raw values; `signed` adds `+`.
  - `pct(x: float, nd: int = 1) -> str` — a fraction as a percentage number without the sign.
  - `count(n: int) -> str` — thousands as `1{,}731`.
  - `money(x: float) -> str` — two decimals with thousands as `1{,}058.93`.
  - `class Registry` with `add(name: str, value: str) -> None` (raises `ValueError` on a duplicate name or a name that is not letters only) and `render() -> str` (sorted `\newcommand{\Name}{value}` lines).
  - `get(obj, path: str, source: str)` — dotted-path lookup that raises `KeyError` naming `source` and `path`.
  - `build() -> Registry`; CLI: no argument writes `numbers.tex`; `--check` exits 1 if the file differs.
- Macro naming: metric (`Rec`, `Map`, `MapTw` for MAP@20, `RPrec`) + setting (`A`, `B`) + method (`Base`, `Prop`, `Greedy`, `Opus`, `Haiku`) + optional `SD`; other names are free but letters only.
