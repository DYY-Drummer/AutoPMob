\section{前回報告（v5）からの主な変更点}
%======================================================================

前回報告の主要結果は，3{,}244式・1{,}107ケースで Set-aware リランカー（reranker-10S）が baseline を全指標で上回るというものであった．その後，査読・修論を見据えて「\textbf{規模を拡大し，より難しい問題でも本手法の優位が保たれるか}」「\textbf{見かけの優位がチューニングや指標選択の副産物でないか}」を検証した．主な変更点は次の通り．

\begin{enumerate}[leftmargin=2em, nosep]
  \item \textbf{データベースを 3.4 倍に拡大}：収録数式を 3{,}244 $\to$ \textbf{11{,}146式}，訓練ケースを 1{,}107 $\to$ \textbf{2{,}838件} に拡大した（\S\ref{sec:data}）．
  \item \textbf{DAE 系の難ケースを 1{,}000 件追加}：常微分方程式（ODE）と代数式が連立する微分代数方程式系（DAE; Differential-Algebraic Equations）を模した難ケースを生成し，難易度勾配を作った（\S\ref{sec:dae}）．
  \item \textbf{評価指標 $\rkc$ を主指標に採用}：従来主指標の MRR\_first は天井（1.0）付近で飽和し改善幅を覆い隠すため，正解式数 $K=n_{\textrm{correct}}$ 件を取り出したときの再現率 $\rkc$（情報検索の R-precision と同義）を導入した（\S\ref{sec:metric}）．
  \item \textbf{難しい問題ほど本手法の優位が拡大}：標準データで $+0.127$，DAE を加えると $+0.210$，DAE のみでは $+0.217$ と，問題が難しくなるほど baseline との差（$\rkc$）が広がることを示した（\S\ref{sec:gradient}）．
  \item \textbf{「分野横断収集は不要」（仮説B）を再検定し結論を更新}：v5 では MRR\_first で差なし（$-0.004$）と結論したが，飽和しない $\rkc$ では \textbf{フル DB が有意に優れる}（$+0.048$，$p=0.044$）ことが判明した（\S\ref{sec:hypoB}）．
  \item \textbf{ハイパーパラメータ頑健性を確認}：13 通りの設定で主指標のばらつきはシード間標準偏差の約 1/10 に収まり，本手法の強さはチューニング由来でないことを定量化した（\S\ref{sec:robust}）．
  \item \textbf{外部ベースライン（LLM 直接生成）との同一条件比較を更新}：現行 11{,}146式 DB 上で baseline・reranker-10S を再評価し，LLM 直接生成と公平に比較した（\S\ref{sec:llm}）．
\end{enumerate}

\subsection{DAE 系難ケースの追加（1{,}000 件）}\label{sec:dae}

本手法の主戦場は「複数の式を\textbf{組合せ}として正しく選ぶ」ことにある．これを厳しく評価するため，物理モデルとして典型的な\textbf{微分代数方程式系（DAE）}——時間微分を含む常微分方程式（ODE）と，それに付随する代数式（速度式・物性式など）が連立した系——を模した難ケースを 1{,}000 件追加した（生成には Anthropic Claude Sonnet 4.5 を使用，variant\_type $=$ \texttt{dae\_X}$N$）．

生成アルゴリズムの要点は次の通り．正解式数を $X \in \{1,2,\dots,10\}$ と段階的に変え，各 $X$ について 100 件ずつ生成した（計 1{,}000 件）：

\begin{enumerate}[leftmargin=2em, nosep]
  \item ランダムに ODE を 1 本選び，正解集合の初期種とする．
  \item その微分変数（例：濃度 $C_A$ の時間変化 $dC_A/dt$）を出力の初期値に加える．
  \item 同一ソース内で\textbf{変数を共有}する式（例：反応速度 $r_A$ を与える Arrhenius 式）を優先的に正解集合へ追加する．
  \item $|$正解集合$| = X$ になるまで反復する．
  \item $X>1$ では，追加した各式の代表変数を出力に加えて\textbf{自由度ゼロ}（DoF$=$0；入力数 $+$ 方程式数 $=$ 出力数 $+$ 既知数）を構成上保証する．
  \item 残りの変数を入力とし，背景文（context）を生成する．
\end{enumerate}

たとえば「連続槽型反応器（CSTR）で，流量 $F$，入口濃度 $C_{A0}$，反応速度定数の係数が既知のとき，槽内濃度 $C_A(t)$ と反応速度 $r_A$ を求めよ」という問題は，物質収支の ODE（$V\,dC_A/dt = F(C_{A0}-C_A) - V r_A$）と Arrhenius 型速度式（$r_A = k\,C_A$，$k = A\exp(-E/RT)$）を\textbf{組合せて}初めて解ける．DAE 系ケースはこの「組合せが必須」という性質を強く持つ．

%======================================================================
\section{評価指標 $\rkc$ の導入}\label{sec:metric}
%======================================================================

前回まで主指標としてきた MRR\_first（最初に当たった正解の順位の逆数；Mean Reciprocal Rank）は，\textbf{正解が1件でも上位に来れば 1.0 に近づく}ため，複数式を揃える能力を測れず，かつ天井付近で飽和して手法間の差を覆い隠す欠点があった．

そこで本版では，正解式が $n_{\textrm{correct}}$ 件あるとき\textbf{上位 $K=n_{\textrm{correct}}$ 件}を取り出し，そのうち正解だった割合 $\rkc = |\,\textrm{Top-}K \cap \mathcal{R}_q\,| / |\mathcal{R}_q|$（$\mathcal{R}_q$ はクエリ $q$ の正解集合）を主指標とする．これは情報検索で標準的な \textbf{R-precision} と同義であり，「\textbf{必要な式をちょうどその本数だけ上位に並べられたか}」を直接測る．飽和しにくく，複数式の組合せ能力を端的に表すため，本手法の評価に適する．補助指標として MRR\_first，MAP（平均適合率；Mean Average Precision，ランキング全体の質），各種 Recall@$K$ も併記する．

\section{実験結果}
%======================================================================

実験条件は特記なき限り共通である：10 シード（source\_id 単位の train/test 分割を変えてリーク防止），Stage~1 候補数 top-$K=50$，リランカー学習 15 epoch，学習率 $1\times10^{-3}$，隠れ層 64 次元．reranker-10S は基本 7 特徴量に Set-aware 3 特徴量（gComp 補完性，gCoh 一貫性，gDom ドメイン整合）を加えた 10 次元である．

\subsection{仮説B の再検定：分野横断収集はやはり有効}\label{sec:hypoB}

加納先生より「\textbf{分野横断的に数式を収集する必要はなく，テストケースで必要な式が含まれていれば十分}」とのご指摘をいただいた（v5 \S2.2）．v5 では本手法の MRR\_first がフル DB と化学工学（ChE）限定 DB でほぼ同じ（$-0.004$）であったため「\textbf{DB 規模の影響は小さい}」と結論していた．

\subsection{外部ベースライン：LLM 直接生成との同一条件比較}\label{sec:llm}

加藤先生より「\textbf{訓練ケースを LLM で生成しているなら，本タスクも LLM に直接解かせれば本手法は不要では}」とのご指摘をいただいた（v5 \S1.3）．これに答えるため，最新の大規模言語モデル（LLM; Large Language Model）である Claude（Sonnet 系）を\textbf{「問題を解く側」}として用いる外部比較を行う．本研究で LLM を使うのはケース生成（既知の式から背景文・入出力を逆算する逆過程）のみであり，検索タスク自体には LLM を使わない点が要点である．

\paragraph{実験設計} LLM に各ケースの背景文（context）と入力・出力変数のみを与え（データベースの存在は伝えない），必要と推測する数式を順位付きで生成させる．生成式を現行データベース（11{,}146式）と文字 $n$-gram の TF-IDF 類似度で照合してランキング化し，本手法と同一の指標で評価する．対象は LLM 評価済みの\textbf{単一ソース 29 件}・\textbf{複数ソース 20 件}のサブセットである．公平を期すため，比較対象の baseline（Stage~1）と reranker-10S（Stage~2）も\textbf{同一サブセット・同一の現行 11{,}146式 DB}で再評価した．reranker/baseline は source\_id 分割の\textbf{テスト側に入ったシードでのみ}各対象ケースを評価しており（当該ケースを学習せず），LLM 直接生成と公平に比較できる．

\paragraph{解釈} 結果は2つの設定で対照的であり，本手法の役割を明確にする．

\begin{enumerate}[leftmargin=2em, nosep]
  \item \textbf{単一ソースの易しい問題では，検索系（両 Stage）が LLM を大きく上回る}：$\rkc$ で reranker-10S 0.975 / baseline 0.982 に対し LLM は 0.707（reranker $-$ LLM $=+0.268$）．この領域では baseline が既に高く，reranker の上乗せは小さい（\S\ref{sec:strat} の「易しい問題は本手法不要」と整合）．
  \item \textbf{複数ソースの難しい問題では，古典 IR 単独（baseline）は LLM を下回る}：$\rkc$ で baseline 0.575 $<$ LLM 0.842．文章類似度と変数 Jaccard だけでは，複数文献の式を\textbf{組合せて}1 つの物理モデルを構成できない．
  \item \textbf{その複数ソース問題で，reranker-10S は baseline を $+0.367$ 改善し（0.575 $\to$ 0.942），LLM をも $+0.100$ 上回る}．MAP でも reranker 0.972 が LLM 0.785・baseline 0.661 を上回る．
\end{enumerate}

すなわち「LLM で直接解けるなら本手法は不要」という懸念に対し，\textbf{易しい問題は検索系が LLM を凌駕し，難しい複数ソース問題では古典 IR では足りず Set-aware リランカーが本質的に必要}（baseline 単独では LLM を下回る）であることが，同一条件の比較で定量的に示された．

なお本比較は単一 29 件・複数 20 件の小規模サブセットであり，リーク防止のため各対象ケースを「テスト分割に入ったシードのみ」で評価した結果，1 ケースあたりの評価回数は単一で平均約 2.2 回・複数で約 1.0 回と限られる（単一は 29 件中 27 件を被覆）．したがって本節の数値は\textbf{傾向の確認}と位置づけ，標本拡充は今後の課題とする（考察の留意点も参照）。

%======================================================================
\section{考察}
%======================================================================

\begin{itemize}[leftmargin=1.5em, nosep]
  \item \textbf{なぜ難ケースで効くか}：DAE 系・複数式・多変数のケースは「単独の式の文章類似度」では正解を絞れず，\textbf{式どうしの変数共有（補完性・一貫性）}という構造情報が効く．Set-aware 特徴量はこの構造を捉えるため，baseline が崩れる領域で優位を保つ．
  \item \textbf{指標選択の重要性}：MRR\_first の飽和は，DB 規模の効果（仮説B）も手法の改善幅も覆い隠していた．$\rkc$ への切替により，DB 拡大の効果と本手法の真の改善幅（標準 $+0.13$，難ケース $+0.22$）が初めて可視化された．
  \item \textbf{頑健性の意義}：13 設定で差が出ないことは，本手法の優位が\textbf{構造的特徴量そのもの}に由来し，学習設定の偶然でないことを示す．これは査読・再現性の観点で重要である．
\end{itemize}

\paragraph{留意点（caveat）} 外部比較（\S\ref{sec:llm}）の LLM 直接生成は単一ソース 29 件・複数ソース 20 件のサブセットで評価しており，標本数が限られる点に留意が必要である．また易しいケース（単一式・少変数）では baseline が天井に達しており，本手法の上乗せ余地が小さいことも併記しておく．

\section{今後の方針}
%======================================================================

\begin{itemize}[leftmargin=1.5em, nosep]
  \item \textbf{修論・論文執筆}：「Set-aware graph features for multi-equation physical model retrieval」を軸に，本版の難易度勾配・指標精緻化・頑健性・外部比較を中核に据える．
  \item \textbf{LLM サブセットの拡充}：外部比較の標本数を増やし，難ケース（DAE 系）での LLM 直接生成も評価する．
  \item \textbf{Set-aware 特徴量の拡張}：listwise 学習，参照集合サイズ $K_{\textrm{ref}}$ の最適化，hard negative の導入．
  \item \textbf{変数記述の意味類似度}：表記揺れを学習的に吸収するため，各変数の物理的意味の自然言語記述を埋め込み比較してグラフをソフトに接続する．
\end{itemize}

\section{まとめ}
%======================================================================

データベースを 11{,}146 式・2{,}838 ケースに拡大し，DAE 系難ケースで難易度勾配を作ったところ，\textbf{問題が難しくなるほど Set-aware リランカーの優位（$\rkc$）が $+0.13 \to +0.22$ と拡大}した．飽和しない指標 $\rkc$ により，分野横断収集の効果（仮説B：$+0.048$，$p=0.044$）が新たに有意と判明し，v5 の暫定結論を訂正した．また 13 通りのハイパーパラメータで主指標が狭い範囲に収まり，本手法の優位がチューニング由来でないことを確認した．外部ベースライン（LLM 直接生成）との同一条件比較は \S\ref{sec:llm} に示す．
