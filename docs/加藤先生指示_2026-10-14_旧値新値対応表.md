報告書 `docs/progress_report_2026-08-31_methods_results.tex` の本文は変えていない。この表は、報告書を書き直すときに数値を差し替えるためのものである。

## 新しい設定と表の読み方

- 第 1 段の重みは (0.3, 0.7)（文章類似度 0.3、変数の一致度 0.7）。候補の件数 N1 = 2,000（全正解式が候補に入る最小の N1 を、分割ごとに訓練と検証のケースで求めると 1,233〜1,880。千の位に切り上げると 10 分割すべてで 2,000）。
- 訓練の不正解の選び方：そのときのモデルの点数が最も高い不正解の候補を 8 件（hard negative。同じ点数なら第 1 段の順位が上のもの。逐次選択の訓練では各段階の参照集合で点数を付け直して選ぶ）。
- 主指標は Recall@20、あわせて MAP（標準の定義：並べた中にない正解式は 0 として K で割る）と MAP@20（上位 20 件で打ち切り）。旧主指標 Recall@K（R@K）は使わない。
- 自由度ゼロ停止はやめた（報告書の §2.2.4 と §7 は削る）。逐次選択は今の手順のまま 20 本まで選ぶ。
- 値は 10 通りの分割の平均 ± 標準偏差。差の括弧は（上回った分割の数、Wilcoxon の符号順位検定の p）。§8 の旧値の p は対応のある t 検定なので、新値にも t 検定の p を併記する。
- 出典の JSON は `experiments/kato1014/`。旧値の出典は各行のメモ。

## 変えた点（すべて）

1. 第 1 段の候補の件数 N1：50（逐次選択と自由度ゼロ停止は 200）→ 2,000（すべての実験で同じ）。
2. 訓練の不正解の選び方：候補から無作為に 8 件 → そのときのモデルの点数が最も高い不正解の候補を 8 件（hard negative。同じ点数なら第 1 段の順位が上のもの。逐次選択の訓練では各段階の参照集合で点数を付け直して選ぶ）。本人の選択（2026-10-15）。N1 = 2,000 の一括の並べ直しで、10 分割すべてで無作為以上（Recall@20 と MAP）を確かめてから採用した。この比較には本実験と同じ 10 分割のテストのケースを使ったので、わずかに楽観的な偏りがありうる（検証用のケースでは確かめていない）。
3. 指標：Recall@K → Recall@20（主）、MAP（標準の定義）、MAP@20。
4. baseline の重み：12 通りから R@K で選んだ (0.4, 0.6) → Recall@20 で選んだ (0.3, 0.7)（A・B とも）。提案手法の第 1 段の重みと同じになった。
5. 自由度ゼロ停止をやめた（§2.2.4、§7）。逐次選択は 20 本まで選ぶ手順のまま。
6. 変えていないこと：特徴量 10 個の定義、一括の並べ直しの参照集合（第 1 段の上位 5 件）、MLP の形と学習の定数（マージン 0.1、不正解 8 件、15 エポック）、層化分割と乱数の種 10 通り。
7. 実装：第 2 段の特徴量をまとめて計算する高速版（`set_aware_reranker.py --fast`、`stage2_fast.py`）で実行した。既定の計算とビット単位で同じ値を返し、種 42 で既存の実行（N1 = 50 と 200、一括と逐次）の per-case と 423/423 件一致する。

## 結論が変わったところ（要約）

- **§4**：最良の baseline（重み (0.3, 0.7)、R@20 0.908）に対し、提案手法（一括、N1 = 2,000）は R@20 0.982、MAP 0.869（A）。R@20 でも +0.074（10/10、p = 0.00195） と大きく上回る（旧版の重み (0.7, 0.3) では R@20 の差がなかった）。B も +0.137（10/10、p = 0.00195）。
- **§5 (i)**：同じ重みの baseline から x1・x2 だけの MLP にすると、上がらずにわずかに下がる（R@20 −0.009（2/10、p = 0.0371）、t 検定 p = 0.15。MAP −0.005（4/10、p = 0.375））。旧版の +0.080 は、重み (0.7, 0.3) より良い重みを学習で見つけた分と考えられる（旧版の 2 特徴量の MLP の R@K 0.601 は、最良の重みの baseline の 0.607 とほぼ同じ）。最良の重みから始めると「重みの学習」の寄与はない。
- **§5 (ii)**：基本の特徴量の向上はほぼ式の特化度 x6（R@20 +0.075（10/10、p = 0.00195））で、旧版と同じ結論。
- **§5 (iii)**：集合の特徴量は R@20 では小さく（+0.006（10/10、p = 0.00195））、MAP で大きい（+0.076（10/10、p = 0.00195））。R@20 が 0.98 付近で頭打ちのため、効果は正解式をより上位に並べる形で出る。
- **§5 PFI**：変数の 6 特徴量をまとめてシャッフルすると R@20 が 0.982 → 0.021（旧版と同じ結論で、より極端）。話題の 4 特徴量は 0.974（低下 +0.008、p = 1.8e-05）で、小さいが 0 と有意に異なる（旧版は p = 0.10）。
- **§6**：一括 < 逐次（推論のみ）< 逐次（訓練も逐次）の順は MAP で保たれる（訓練も逐次 − 一括：A +0.016（10/10、p = 0.00195）、B +0.018（10/10、p = 0.00195）。正解式 8 本以上で A +0.031（10/10、p = 0.00195））。R@20 は天井に近く、A の差は有意でない（+0.001（7/10、p = 0.084））。N1 = 2,000 で全正解式が候補に入るので、§6 で N1 を 200 に広げた理由と付録 C の N1 の比較は不要になる。
- **§8**：N1 = 2,000 の候補の中でも話題の特徴量は正解式を見分ける（AUC：潜在意味類似度 0.913、文章類似度 0.852。旧版の候補 50 件では 0.594 と 0.437）。候補内の相関も −0.052（旧版 −0.404）。旧版の原因の (1) 候補の話題がそろう、(2) 候補の選び方が作る逆相関、は N1 = 50 で生じていたもので、N1 = 2,000 ではほぼ消える。それでも x7・x3 を足して訓練し直しても上がらない（x7 −0.007（4/10、p = 0.275）。x3 はむしろわずかに下がる：−0.017（1/10、p = 0.0488）、t 検定 p = 0.13）。x10 は R@20 では効かないが MAP をわずかに上げる（+0.009（8/10、p = 0.00977））。分野ラベルを群にまとめて x7 を群で数える（説明文が群のどれかのラベルを含めば 1）と、粗くするほどむしろ下がる（R@20：表記をそろえた 1,958 種 −0.022（2/10、p = 0.00977）、100 群 −0.028（2/10、p = 0.0273）、40 群 −0.036（3/10、p = 0.0273））。旧版の k-means の 100 群・40 群は、式のラベルを群の名前に置き換えたので x7 がほとんど 1 にならず（1,823 ケース中 5 件）、合併の効果を測れていなかった。(3) x10 の打ち消し合いは見えなくなった（sep > 0 の 1,358 件と sep < 0 の 234 件で、Mann–Whitney p = 0.081。旧版は p = 1.3e-8）。
- **§9.1**：N1 = 2,000 では第 1 段の見逃しがなくなる（種 42：上位 20 件に入らない正解式は 1,579 本中 19 本で、すべて第 2 段の並べ方による。旧版は N1 = 50 で 61.8% が第 1 段）。
- **§7**：自由度ゼロ停止をやめたので、節ごと削る。
