\section{Problem Formulation}
\label{sec:formulation}

In this thesis a physical model is a set of equations from which the output variables can be
computed once the input variables are given. Kato and Kano formulated model building from
documents as the combination of extracted equations, and they defined four requirements that the
equation set $S$ of a desired model must meet\cite{CombineEq}. Let $\mathcal{I}$ and $\mathcal{O}$
be the input and output variables, and let $V(S)$ be the variables that appear in the equations
of $S$.
% 要件の名称: 原典の要旨（OpenAlex 収録、2026-10-12 確認）が挙げる名称は "input–output completeness and
%   consistency" のみ。要件 1 は要旨の語、要件 2〜4 は内容に沿った呼び名（内容は日本語版報告 §2.1 と同じ）。
\begin{enumerate}
  \item Input--output completeness: every input and output variable appears in $S$, that is,
    $\mathcal{I} \cup \mathcal{O} \subseteq V(S)$.
  \item Degree-of-freedom consistency: the degrees of freedom of $S$, the number of variables minus
    the number of equations\cite{Seborg},
    \begin{equation}
      N_{\mathrm{DoF}}(S) = |V(S)| - |S| ,
      \label{eq:dof}
    \end{equation}
    equal the number of input variables, $N_{\mathrm{DoF}}(S) = |\mathcal{I}|$. Under
    requirement~1 this is equivalent to $|V(S) \setminus \mathcal{I}| = |S|$: once the inputs are
    given, $S$ has exactly as many unknown variables as equations.
  \item Solvability: every variable other than the input and output variables appears in at least
    two equations of $S$.
  \item Unique constant equations: each variable that represents a constant is defined by a single
    equation that sets it to that constant.
\end{enumerate}
The four requirements are necessary conditions; a set that meets them need not serve as a
model\cite{CombineEq}.

The combination method of Kato and Kano takes a given set of equations and returns every
combination that meets the requirements. This study addresses the step before it: from a large
database built from many documents, choose the equations that the combination method needs, that
is, the equations needed to build the desired model. The proposed method can therefore sit
upstream of the combination method, and it can also serve to find useful equations among a vast
number of equations.
A query is a triple $q = (c, \mathcal{I}, \mathcal{O})$, where the description $c$ states the
desired model in natural language and $\mathcal{I}$ and $\mathcal{O}$ list the symbols of the
input and output variables; we write $\mathcal{Q} = \mathcal{I} \cup \mathcal{O}$ for the query
variables. The database $\mathcal{E} = \{e_1, \dots, e_N\}$ stores five items for each equation
$e_j$: its \LaTeX{} expression; its variable set $V(e_j)$, with a text that defines each symbol; a
context text, which the extracting language model wrote out from the passage around the equation
to explain its physical meaning; its source; and a domain label $\mathrm{dom}(e_j)$, a free-text
name of the field or process that the language model chose rather than an entry of a fixed
taxonomy (Section~\ref{sec:db}). Two variables are the same only
when their symbols match exactly, both between the query and an equation and between two
equations, and the method applies no notational normalization, so $C_A$ and $C_A(t)$ are
different variables. The method does not read the definitions of the symbols either: two
variables with the same symbol count as one even when their definitions differ
(Section~\ref{sec:db} counts such symbols in the database).
% source: extract_equations.py EXTRACTION_PROMPT（context_text: "surrounding text explaining physical meaning"）;
%         two_stage_query_conditioned.py norm() は strip() のみ（記号の正規化なし）、式の変数は variables のキーだけで、
%         定義の文章（値）は手法のどこでも使わない（docs/加藤先生コメント2_事実確認_2026-10-20.md 項目 9.3）

The method outputs a ranking of the database. It places the equations most likely to be needed
for the desired model at the top and presents the top $n$, with $n = 20$ in this thesis.

To evaluate the method, each test case designates one ground-truth set
$\mathcal{R}_q \subset \mathcal{E}$, the equations of the requested model
(Section~\ref{sec:cases}). We call the equations in $\mathcal{R}_q$ correct and all other
equations incorrect, and we write $K = |\mathcal{R}_q|$ for the number of ground-truth equations.
Equations are identified by an identifier that combines the source and the equation number, so an
equation identical to a correct one but taken from another source counts as incorrect;
Section~\ref{sec:overall} also reports the results when such equations count as correct.

\section{Stage 1: Candidate Retrieval}
\label{sec:stage1}

The first stage scores every equation in the database independently and keeps the top $N_1$ as
the candidate set $C_q$. The score mixes one text term and one variable term,
% source: two_stage_query_conditioned.py stage1() L248-254（w_text*ts + w_var*vs, argsort 上位 N_1）;
%         eq_text() L71（context_text・equation・domain を連結）
\begin{equation}
  s_1(q, e_j) = w_{\mathrm{t}} \cos\!\big(\mathrm{tfidf}(c), \mathrm{tfidf}(t_j)\big)
              + w_{\mathrm{v}} \, J\!\big(\mathcal{Q}, V(e_j)\big) ,
  \label{eq:stage1}
\end{equation}
where $t_j$ joins the context text, the expression, and the domain label of equation $e_j$. The
first term, the text similarity, compares the description with this text through
term-frequency--inverse-document-frequency (TF-IDF) vectors\cite{Salton}, which weight each word
by its count in a text and by its rarity across the equation texts of the database; the vectors
use word unigrams and bigrams over a vocabulary built from all $t_j$. The second term, the
variable overlap, is the Jaccard similarity $J(A, B) = |A \cap B| / |A \cup B|$ between the query
variables and the variables of the equation. The weights $w_{\mathrm{t}}$ and $w_{\mathrm{v}}$
balance the two terms. Ranking the whole database by Eq.~\eqref{eq:stage1} is a classical
information-retrieval method\cite{Manning}, and Chapter~\ref{Experiment} uses it, without a
learned model or a candidate set, as the baseline.

The second stage reranks only the candidates, so the fraction of ground-truth equations among the
candidates --- the candidate coverage --- bounds what the second stage can achieve. The coverage
depends on both the weights and $N_1$. We set $N_1$ so large that every ground-truth equation
enters the candidates (Section~\ref{sec:compared}).

\section{Stage 2: Set-aware Reranking}
\label{sec:stage2}

The second stage judges each candidate not on its own but against the equations already at hand.
Table~\ref{tab:features} lists the ten features it uses. Seven of them compare the query with a
single equation: two measure topical closeness of the description ($f_1$, $f_3$), one matches the
domain label against the description ($f_7$), and four measure how the equation's variables relate
to the query variables ($f_2$, $f_4$, $f_5$, $f_6$). The remaining three are the set-aware features
that this study introduces. They compare the candidate with a reference set $R$, the equations
against which the candidate is judged: the top $m$ equations of Stage~1 in static reranking, and the
equations already selected in sequential selection (Section~\ref{sec:seq}). A candidate that
belongs to $R$ is compared with $R$ without itself.
% source: set_aware_reranker.py K_REF=5 L95, compute_set_aware_features L119-137（自己除外）

Complementarity $g_{\mathrm{Comp}}$ asks what the candidate adds: it is the fraction of query
variables that appear in the candidate but in no equation of the reference set. Coherence
$g_{\mathrm{Coh}}$ asks whether the candidate connects to what is already selected: it is the
fraction of the candidate's variables shared with the reference set. Domain agreement
$g_{\mathrm{Dom}}$ asks whether the candidate comes from the same topic as the reference set: it is
the fraction of reference equations whose domain label equals the candidate's. The first two
encode how equations determine one another's variables, the third encodes topical consistency, and
Section~\ref{sec:mechanism} measures what each contributes.

Two features deserve a remark. The domain match $f_7$ compares the strings without regard to case.
The latent similarity $f_3$ applies latent semantic analysis\cite{LSA}: we factorize the TF-IDF
matrix of all equation texts with a truncated singular-value decomposition (SVD) into 256
dimensions, project the query into the same space, and take the cosine similarity. In this space,
words that tend to appear in the same texts share dimensions, so the similarity grows when the two
texts contain words that appear in similar texts, even without shared words. Unlike $f_1$, the
query text here also lists the input and output variable symbols, so $f_3$ sees both the
description and the requested variables.
% source: two_stage_query_conditioned.py case_text(c, io=True) → svd クエリ; 256 成分

A multilayer perceptron (MLP) maps the ten features $x(q, e)$ of a candidate to a score
$f(x(q, e))$. It has two hidden layers of 64 units with rectified-linear activation and dropout
0.1.
% source: two_stage_query_conditioned.py class Reranker L197-205（Linear-ReLU-Dropout ×2 + Linear）
We train it with a pairwise ranking loss\cite{LTR} that asks every correct candidate to outscore
the incorrect candidates of the same case by at least a margin $\gamma$. For a training case $q$,
a ground-truth equation $e^{+} \in \mathcal{R}_q \cap C_q$, and an incorrect candidate
$e^{-} \in C_q \setminus \mathcal{R}_q$,
\begin{equation}
  \ell(q, e^{+}, e^{-}) = \max\!\big(0,\; \gamma - f(x(q, e^{+})) + f(x(q, e^{-}))\big) .
  \label{eq:loss}
\end{equation}
For each training case we choose $n_{\mathrm{neg}}$ incorrect candidates and pair every correct
candidate with each of them. We compare two ways of choosing them and let the validation cases
decide between them (Section~\ref{sec:compared}): (a) at random, and (b) the incorrect candidates
that the MLP, at that point of training, scores highest (hard negatives). We add (b) because, with
a large $N_1$, most randomly chosen incorrect candidates already trail the correct ones by more
than the margin and contribute no loss. Each update averages $\ell$ over all pairs of a batch of 16
training cases. Chapter~\ref{Experiment} gives the values of $\gamma$, $n_{\mathrm{neg}}$, and the
other constants, and \ref{app:hyper} lists them all. We call this configuration
reranker-10S, and reranker-7 for the variant that drops the three set-aware features.

\section{Sequential Selection}
\label{sec:seq}

Static reranking fixes the reference set to the top $m$ equations of Stage~1 and scores all
candidates in one pass. When a case has many ground-truth equations, the equations that actually
rise to the top drift away from this fixed reference set. Sequential selection therefore replaces
the reference set with the equations selected so far and selects one equation at a time:
\begin{enumerate}
  \item It takes first the candidate with the highest static score, the score computed against the
    fixed reference set.
  \item It then recomputes the set-aware features of the remaining candidates against the equations
    selected so far and takes the candidate with the highest score.
  \item It repeats step~2 until it has selected $n$ equations or exhausted the candidates; the
    unselected candidates follow in the order of their static scores.
\end{enumerate}
% source: set_aware_reranker.py greedy_order L213-243（先頭は静的スコア最大、以降は再計算、
%         greedy_cap=20、残りは init_scores 順）
Sequential selection comes in two variants that differ in how the MLP is trained. Greedy
selection at inference uses the MLP trained for static reranking. Learned greedy selection also
trains on the sequential contexts. It puts ground-truth equations, not the equations the MLP
itself would select, into the reference set during training, as teacher forcing does when a model
that generates a sequence learns with the correct preceding outputs in place of its own.

Learned greedy selection orders the ground-truth equations among the candidates of a training case
by their Stage-1 rank, $e^{+}_1, e^{+}_2, \dots$, and adds a loss at each step $t = 1, 2, \dots$.
At step~$t$ it treats $e^{+}_1, \dots, e^{+}_{t-1}$ as the equations already selected and uses them
as the reference set (the top $m$ equations of Stage~1 at $t = 1$); with the features computed
against this reference set, it adds the loss of Eq.~\eqref{eq:loss} for the next ground-truth
equation $e^{+}_t$ and the chosen incorrect candidates. For a case with three ground-truth
equations, step~1 learns to rank $e^{+}_1$ above the incorrect candidates against the Stage-1
reference set, step~2 learns to rank $e^{+}_2$ above them against $\{e^{+}_1\}$, and step~3 learns
to rank $e^{+}_3$ above them against $\{e^{+}_1, e^{+}_2\}$. A case contributes at most eight steps.
Training thus asks the same question as inference --- which equation to select next, given the
ones already selected.
% source: set_aware_reranker.py run_mode の train_greedy ブロック（pos は候補の順＝第 1 段の順位の順、
%         t=0 は静的参照で「種」を学習、greedy_train_cap=8、sel_db に正解を足す teacher forcing、hard negative は
%         段階ごとの点数で選ぶ）
Teacher forcing keeps training stable but leaves a train--test gap: at inference the reference set
holds the model's own selections, which may include mistakes (Section~\ref{sec:limitations}).
